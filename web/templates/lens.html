Faq

Does GO Lens cost anything?
No. The graduate-oracle API is free during the launch promo, and GO Lens uses the public probe endpoint. After the promo ends, the API gets a paywall — but GO Lens itself will stay free; it'll just use the free-tier endpoints by default.
Does it slow down Axiom / GMGN / etc?
No. The script attaches one mousemove listener and only fires an API call when you hover a recognizable mint address. Results are cached per-mint for 30s, so repeated hovers don't hit the wire.
Can the host site see my graduate-oracle queries?
No. The fetch goes directly from your browser to graduateoracle.fun via Tampermonkey's GM_xmlhttpRequest, which bypasses the host page's request scope. Axiom/GMGN/etc. can't see what mints you're probing.
Will it work on a new terminal that I don't see listed?
Probably — the script auto-detects any base58 Solana mint address (32–44 chars) in the DOM. If a site renders mints as plain text, hover works. If you want first-class support for a specific terminal, ping @GraduateOracle on X.
Is the source code open?
The userscript IS the source — view it here. Single file, no build step, no minification. Read it before you install.
Chrome Web Store version coming?
Yes — same code, packaged as a Manifest V3 extension. Tampermonkey ships today; the Chrome Store version submits in week 2.
